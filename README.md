# MDataAccess for Cursor

Connect Cursor to **MDataAccess**, a hosted MCP server for business, people, company, lead, and web intelligence.

## MCP endpoint

`https://api.mdataaccess.com/mcp/`

Transport: **Streamable HTTP**

## Capabilities

- Read public web content
- Enrich companies
- Enrich people
- Search companies
- Search people
- Find decision-makers
- Find sales leads

## Cursor

This repository contains the lightweight Cursor Marketplace connector for MDataAccess. The MDataAccess service itself remains hosted separately.
